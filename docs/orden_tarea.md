# Orden de tarea: síntesis operativa

**Asignatura:** Análisis del Contexto Nacional y Global  
**Nivel:** Octavo semestre, Carrera de Economía  
**Modalidad:** trabajo autónomo grupal (3–5 estudiantes)  
**Apertura:** 10 de julio de 2026, 00:00  
**Cierre:** 24 de julio de 2026, 23:59  
**Herramientas:** Visual Studio Code, GitHub, Vercel y generador PDF

## Producto

Sistema multiagéntico para analizar un problema económico nacional conectado
con el contexto internacional. Debe incluir Ecuador y al menos tres economías,
datos trazables, análisis económico/estadístico o econométrico, dashboard
público, informe PDF reproducible y evidencia de coordinación entre agentes y
subagentes.

## Entregables

1. Repositorio público de GitHub.
2. Dashboard público en Vercel.
3. Informe PDF de 12–20 páginas, sin anexos.
4. Carpeta completa comprimida.
5. Diagrama multiagente.
6. Bitácora, diccionario y base procesada.
7. Presentación breve.
8. Evidencia de participación individual.
