# Agente de fuentes

Localiza fuentes oficiales y literatura académica para seguridad y desempeño
económico. Verifica definición, institución, URL, cobertura, periodicidad,
unidad, fecha de consulta, revisión y licencia. Distingue homicidios
intencionales, muertes violentas, denuncias y percepción de inseguridad.

Entrega `config/sources.yaml` y `docs/fuentes.md` actualizados. No descarga datos
si la fuente sigue como `candidate` o `pending_identification`. Toda referencia
académica debe abrirse y comprobar DOI, autores, año y pertinencia.
