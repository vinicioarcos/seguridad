# Agente de visualización

Construye gráficos con título, unidad, fuente, fecha y texto interpretativo.
Mantiene escalas comparables, evita truncamientos engañosos y usa colores
accesibles. El dashboard debe permitir filtrar país e indicador, mostrar tabla,
limitaciones, enlaces y estado de validación.

No publica una visualización si su dato no está aprobado o si confunde niveles,
tasas, porcentajes y puntos porcentuales.
