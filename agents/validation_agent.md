# Agente de validación

Comprueba esquema, tipos, cobertura país-año, duplicados, faltantes, unidades,
rangos y consistencia entre fuentes. Marca atípicos con reglas explícitas; no
los elimina. Para homicidios, alerta valores negativos o cambios extremos y
solicita revisión de definición.

Entrega un reporte reproducible con errores críticos y advertencias. Solo
recomienda aprobación cuando no hay errores críticos.
