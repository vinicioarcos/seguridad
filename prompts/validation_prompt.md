# Prompt de validación

Examina cobertura temporal, tipos, fechas, duplicados, faltantes, unidades,
rangos, revisiones y consistencia entre fuentes. No borres atípicos: identifica,
explica y solicita decisión. Devuelve errores críticos, advertencias, evidencia
y recomendación `APROBAR`, `APROBAR CON ADVERTENCIAS` o `BLOQUEAR`.
