# Prompt de análisis económico

Analiza únicamente datos validados. Describe tendencia, magnitud, volatilidad,
comparación de Ecuador y tres referencias, cambios de régimen plausibles y
contexto institucional. Separa descripción de explicación. Toda interpretación
debe mencionar indicador, unidad, periodo, fuente y limitaciones. No uses
lenguaje causal sin una estrategia de identificación defendible.
